# Blockchain-Based College Voting System

## Project Description

Blockchain-Based College Voting System is a secure, transparent, and efficient web-based application developed for conducting student elections in colleges using blockchain technology. The main objective of this project is to provide a fair voting platform where students can vote without the risk of duplicate voting, fake votes, or vote tampering.

Traditional voting systems often face problems such as manipulation, lack of transparency, and unauthorized access. This project solves these issues by implementing blockchain concepts to create a secure and tamper-proof voting process.

In this system, students can log in using their Student ID and password to vote for positions like Class Representative (CR), Student Council President, Club Head, Department Representative, Hostel Representative, and other leadership roles. Each student can vote only once for a specific position, ensuring the principle of one student, one vote.

The admin panel allows college authorities to manage the complete election process by adding candidates, creating voting positions, starting or ending elections, monitoring results, and declaring winners. Each vote is stored as a separate blockchain block containing voter ID, selected candidate, timestamp, previous hash, and current hash, ensuring transparency and data integrity.

This project combines frontend development, backend management, database handling, and blockchain logic, making it an ideal final-year college project for demonstrations, presentations, and viva examinations.

## Features

* Student Registration and Login
* Admin Login and Dashboard
* Candidate Management
* One Student One Vote System
* Blockchain-Based Vote Storage
* Secure and Transparent Voting
* Real-Time Result Display
* Winner Declaration

* Mobile Responsive Interface
